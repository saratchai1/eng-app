# ที่มาของแอปและขอบเขตการพัฒนาใหม่

วันที่สำรวจเว็บอ้างอิง: **21 พฤศจิกายน 2569 (2026-11-21), เวลาไทย**  
เว็บอ้างอิง: [ช่างคิด Engineering Apps](https://changkid-engapp.com/)  
โครงการที่พัฒนา: `saratchai1/eng-app`

เอกสารนี้บันทึกสิ่งที่สังเกตจากหน้าสาธารณะและขอบเขตที่เลือกพัฒนาเอง เพื่อให้ตรวจสอบได้ว่าความสามารถใดมาจากการดูตัวอย่าง ความสามารถใดเป็นแบบจำลองใหม่ และส่วนใดยังไม่ได้ทำ ไม่ใช่เอกสารรับรองความเทียบเท่ากับแอปต้นฉบับหรือการรับรองมาตรฐานวิศวกรรม

## สิ่งที่ตรวจพบจากหน้าสาธารณะ

หน้ารวมแอปมีการค้นหา ตัวกรองหมวด รายการอัปเดต แบบเสนอแอป และรายการเครื่องมือ 20 รายการ หมวดที่มองเห็นประกอบด้วยงานออกแบบ บริหารงาน ราคา/BOQ แบบ การจราจร เรียนรู้ และอื่น ๆ จำนวนหมวดไม่จำเป็นต้องเท่ากับจำนวนหมวดที่มีเครื่องมืออยู่จริงในวันสำรวจ

จากการตรวจหน้ารายการ การเข้าใช้เครื่องมือแสดงเงื่อนไขให้เข้าสู่ระบบ จึงสังเกตได้เฉพาะรายการและคำอธิบายที่เปิดเผยต่อสาธารณะ **ไม่ได้เข้าไปทดสอบสูตร ขั้นตอนทำงาน หรือฐานข้อมูลภายในของเครื่องมือที่ป้องกันด้วยการเข้าสู่ระบบ** ข้อความในหน้ารายการเป็นคำกล่าวถึงความสามารถของผู้ให้บริการ ไม่ใช่ผลการทดสอบความสามารถเหล่านั้น

ผู้ใช้สั่งให้เวอร์ชันของโครงการนี้ **ไม่ต้องมีการล็อกอิน** จึงออกแบบให้เปิดใช้งานเครื่องมือและเก็บงานในเบราว์เซอร์ได้ทันที ไม่มีการจำลองว่าล็อกอิน Google/LINE สำเร็จ ไม่มีการเชื่อมบัญชีหรือใช้สิทธิ์บริการต้นฉบับ

## ตารางขอบเขต 20 เครื่องมือ

คอลัมน์เว็บอ้างอิงใช้ชื่อที่บันทึกได้ เช่น `Concrete Design Pro` และ `Easy Planning Pro` ส่วนชื่อที่ไม่ได้บันทึกเต็มใช้คำอธิบายประเภทงาน ไม่ถือเป็นการถอดชื่อการค้าอย่างเป็นทางการ ชื่อเมนูและ ID ในโครงการนี้เป็นชื่อที่ตั้งขึ้นสำหรับการพัฒนาใหม่

| ID ในโครงการนี้ | รายการ/ประเภทที่พบในเว็บอ้างอิง | ขอบเขตเวอร์ชันแรกของเรา | ส่วนที่ยังไม่เทียบเท่าต้นฉบับ |
| --- | --- | --- | --- |
| `boq-building` | Building BOQ | ตารางต้นทุนงานอาคาร แก้รายการ ปริมาณ หน่วย ราคาวัสดุ และค่าแรงได้ | ไม่ใช่ฐานราคาปัจจุบันหรือการถอดแบบอาคารอัตโนมัติ |
| `boq-road` | Roads BOQ DOH | ตารางต้นทุนงานทางที่ผู้ใช้ตรวจและแก้ข้อมูลได้ | ไม่ใช่โปรแกรมหรือฐานข้อมูลรับรองของกรมทางหลวง |
| `boq-irrigation` | Irrigation BOQ | ตารางต้นทุนงานชลประทาน | ไม่ใช่ฐานราคาหรือแบบคำนวณราชการที่รับรองแล้ว |
| `boq-warehouse` | Warehouse BOQ | ตารางต้นทุนงานโกดัง/คลังสินค้า | ไม่สร้างแบบโครงสร้างหรือปริมาณจากโมเดลอาคาร |
| `quantity-building` | Building official cost form 2569 | คำนวณปริมาณเรขาคณิตขององค์ประกอบอาคารอย่างง่าย; การประมาณเหล็กด้วยอัตราต่อปริมาตรต้องแสดงว่าเป็นค่าที่ผู้ใช้สมมติ | ไม่สร้างบัญชีดัดเหล็ก BBS และไม่ใช่แบบฟอร์มราคากลางราชการปี 2569 |
| `quantity-road` | Roads/bridges/culvert official cost form 2569 | คำนวณปริมาณชั้นทางจากความยาว ความกว้าง และความหนา | ไม่วิเคราะห์สะพาน/ท่อเหลี่ยม และไม่สร้างแบบฟอร์มราชการครบชุด |
| `quantity-canal` | Irrigation official cost form 2569 | เรขาคณิตคลองหน้าตัดสี่เหลี่ยมคางหมูและปริมาณตามมิติที่กรอก | ไม่ออกแบบชลศาสตร์ เสถียรภาพลาด หรือรายการราชการครบชุด |
| `price-book` | Price Live | รายการราคาตัวอย่างที่ผู้ใช้แก้ไขเอง | ไม่มี feed ราคา ไม่มีการยืนยันว่าเป็นราคาล่าสุดหรือราคาจังหวัดใด |
| `factor-k` | Factor K | ดัชนีถ่วงน้ำหนักจากน้ำหนักและอัตราส่วนดัชนีที่ผู้ใช้ป้อน | ไม่ใช่สูตรทางราชการทั้ง 35 สูตร ไม่ใช่การพิจารณาสิทธิหรือยอดชดเชยตามสัญญา |
| `drawing-takeoff` | PDF to BOQ | โหลดภาพ ตั้งสเกลด้วยระยะอ้างอิง แล้ววัดระยะ พื้นที่ และนับจุด | ไม่อ่าน PDF อัตโนมัติ ไม่ OCR ไม่จำแนกวัสดุ/เหล็กจากแบบและไม่ถอด BOQ อัตโนมัติ |
| `planning` | Easy Planning Pro | เครือข่ายงาน CPM, Gantt และความก้าวหน้าถ่วงน้ำหนักจากข้อมูลที่ป้อน | ไม่เชื่อมตารางงานหลายองค์กรหรือฐานข้อมูลโครงการภายนอก |
| `inspection` | Home Check | เช็กลิสต์ตรวจงาน บันทึกข้อสังเกตและภาพประกอบในเบราว์เซอร์ | ไม่ใช่ระบบส่งมอบ/อนุมัติหลายผู้ใช้ ไม่มี server sync |
| `rc-beam` | Concrete Design Pro | ตรวจโมเมนต์ของหน้าตัดคานสี่เหลี่ยมเสริมเหล็กด้านรับแรงดึงแบบจำกัดขอบเขต | ไม่ใช่ 3D/FEA, AutoSolver, ออกแบบอาคารทั้งหลัง, ตรวจทุก failure mode หรือ BBS |
| `rc-slab` | Concrete Design | ตรวจแรงดัดของแถบพื้นกว้าง 1 เมตรในแบบจำลองที่ระบุ | ไม่ใช่การวิเคราะห์พื้นสองทางหรือ finite element และไม่ตรวจ punching/shear/deflection ครบถ้วน |
| `retaining-wall` | Retaining wall | แรงดันดิน Rankine, น้ำ, การเลื่อน การพลิก และแรงกดฐานของกรณีสถิตที่กำหนด | ไม่ตรวจ global slope stability, settlement, seepage/piping, แผ่นดินไหว หรือกำลังโครงสร้างกำแพงครบถ้วน |
| `footing` | Eccentric Footing | แรงกดดินฐานสี่เหลี่ยมเยื้องศูนย์หนึ่งแกน รวมการสัมผัสเต็ม/บางส่วน | ไม่ออกแบบเหล็กฐาน ไม่ตรวจ punching ไม่รองรับโมเมนต์สองแกนหรือปฏิสัมพันธ์ดิน-โครงสร้างครบรูปแบบ |
| `shoring` | Japanese scaffolding | เปรียบเทียบแรงโน้มถ่วงกับ working capacity ที่ผู้ใช้กรอกจากเอกสารรับรองของระบบจริง | ไม่รับรองกำลังชุดนั่งร้าน ไม่วิเคราะห์ buckling, bracing, connection, ลม หรือการติดตั้งครบชุด |
| `drawings` | DOH Standard Drawing | สร้างและดาวน์โหลดแผนภาพ SVG เชิงอธิบายที่เขียนใหม่ | ไม่ใช่คลังแบบมาตรฐานกรมทางหลวง และไม่ใช่แบบสำหรับก่อสร้าง |
| `guide` | Price guide 2569 | บทเรียนสั้นเรื่องการประมาณราคาและการใช้แบบจำลองที่เขียนขึ้นใหม่ | ไม่ใช่การคัดลอกคู่มือทางราชการปี 2569 หรือข้อกำหนดทางสัญญา |
| `quiz` | Civil exam | แบบฝึกหัดที่แต่งใหม่ 12 ข้อพร้อมคำอธิบาย | ไม่ใช่คลังข้อสอบต้นฉบับประมาณ 2,500 ข้อ และไม่อ้างว่าเป็นข้อสอบจริง |

ตารางนี้เป็นขอบเขตที่ตกลงสำหรับเวอร์ชันแรก ความครบถ้วนของแต่ละพฤติกรรมต้องตรวจเทียบกับโค้ดและผลทดสอบของเวอร์ชันที่ส่งมอบ ห้ามนำจำนวน 20 เมนูไปอธิบายว่าทำความสามารถทั้งหมดของทั้ง 20 แอปต้นฉบับครบแล้ว

## หลักของการพัฒนาใหม่

- สร้างโค้ด หน้าจอ แผนภาพ ตัวอย่างราคา บทเรียน และแบบฝึกหัดของโครงการนี้เอง ใช้เว็บอ้างอิงเพื่อเข้าใจประเภทงานและการจัดรายการ
- ไม่คัดลอกโลโก้ ประวัติบุคคลหรือเจ้าของบริการ โค้ดส่วนตัว ฐานสมาชิก ฐานราคา หรือคลังข้อสอบ/แบบที่จำกัดสิทธิ์
- ไม่ใช้ชื่อหรือหน้าตาเพื่อแสดงว่าโครงการนี้เป็นบริการต้นฉบับ ชื่อเมนูของเราสื่อถึงขอบเขตที่ทำจริง
- ไม่มีระบบล็อกอิน การชำระเงิน สมาชิก การดึงข้อมูลสด หรือการซิงก์งานไปเซิร์ฟเวอร์ของบริการอื่น
- ข้อมูลตัวอย่างใช้สาธิตการทำงาน ผู้ใช้ต้องระบุแหล่งข้อมูลจริงของโครงการเมื่อนำไปประมาณราคา/วิเคราะห์
- การบันทึกงานในเบราว์เซอร์ไม่เท่ากับการสำรองข้อมูลบนเซิร์ฟเวอร์ ควรใช้การส่งออกงานตามที่แอปรองรับ

## แหล่งอ้างอิงของแบบจำลองวิศวกรรม

ใช้แหล่งปฐมภูมิที่เปิดเผยได้สำหรับสมการทั่วไป เขียนคำอธิบายและโค้ดใหม่ ไม่คัดลอกบทของมาตรฐาน เอกสารด้านล่างเป็นที่มาของหลักการบางส่วน ไม่ใช่คำรับรองว่าแอปทำข้อกำหนดทั้งหมดของเอกสารนั้น

### กำแพงกันดินและน้ำ

[USACE EM 1110-2-2502 — Floodwalls and Other Hydraulic Retaining Walls, 1 August 2022](https://www.publications.usace.army.mil/Portals/76/Users/182/86/2486/EM%201110-2-2502.pdf?JMIwQ0zD=0N5Sl)

จุดอ้างอิง: §6.6 น้ำ/น้ำใต้ดิน, Eq. 6.15 สัมประสิทธิ์ Rankine, §6.8 surcharge, §7.3 การเลื่อน และ Eq. 7.2 ตำแหน่งแรงลัพธ์ แบบจำลองของเราจำกัดผิวกำแพงแนวดิ่งเรียบ ผิวดินหลังราบ ดินไม่มี cohesion และแรงสถิต แยก effective earth pressure ออกจาก hydrostatic pressure; ต้องคิดแรงยกใต้ฐานและโมเมนต์อย่างสอดคล้องกับจุดอ้างอิงความสูง

อัตราส่วนแรงเสียดทานฐานต่อแรงด้านข้างอย่างง่ายเป็นเพียงการคัดกรอง เอกสาร USACE ฉบับนี้มีวิธี developed/reduced shear strength และข้อกำหนดเพิ่มเติม จึงไม่อ้างว่าการใช้ `μN/P` เพียงอย่างเดียวเป็นการตรวจตาม USACE ครบถ้วน ค่าเป้าหมายความปลอดภัยในตัวอย่างต้องระบุว่าเป็นสมมติฐานของการคัดกรอง

### ฐานรากเยื้องศูนย์และการสัมผัสดิน

[FHWA-HRT-14-094, Chapter 4 — Eccentricity](https://www.fhwa.dot.gov/publications/research/infrastructure/bridge/14094/004.cfm)

จุดอ้างอิง: Figures 7–16 และคำอธิบายช่วง middle third/footing liftoff ใช้สมดุลของฐานแข็ง รับแรงเยื้องศูนย์หนึ่งแกน และสมมติว่าดินรับแรงดึงไม่ได้ เมื่อแรงลัพธ์อยู่นอก middle third ต้องเปลี่ยนเป็นแรงกดสามเหลี่ยมบนพื้นที่สัมผัสบางส่วน เมื่อแรงลัพธ์อยู่นอกขอบฐานไม่ถือว่ามีสมดุลแบบรับแรงอัดอย่างเดียว

ความกว้างพื้นที่สัมผัสสามเหลี่ยม `3(B/2 − |e|)` ต่างจากความกว้าง effective bearing `B − 2|e|` และใช้แทนกันไม่ได้ การเทียบ allowable pressure ต้องใช้ gross/net convention เดียวกับรายงานปฐพี ไม่มีการประมาณ allowable pressure จากชื่อชนิดดินเพียงอย่างเดียว

### กำลังแรงดัดคอนกรีตเสริมเหล็ก

[FHWA Comprehensive PSC Bridge Design Example — Step 4](https://www.fhwa.dot.gov/bridge/lrfd/pscus04.cfm)

ส่วน rectangular reinforced concrete section ที่ไม่มี prestressing และไม่มี compression reinforcement ให้สมดุลของ equivalent rectangular stress block และกำลังโมเมนต์จากแรงคู่ควบ ใช้เป็นที่มาของสูตรหน้าตัดสี่เหลี่ยมเสริมเหล็กรับแรงดึง แบบจำลองนี้ไม่ใช่การวิเคราะห์สะพานตามชื่อเอกสารและไม่ครอบคลุมการออกแบบสมาชิกทั้งชิ้น

[Caltrans Bridge Design Practice 5.4 — Precast Pretensioned Box Girders, October 2022](https://dot.ca.gov/-/media/dot-media/programs/engineering/documents/bridge-design-practices/202210bdpchapter54precastpretensionedboxgirdera11y.pdf)

ตัวอย่างหน้า 5.4-49 แสดง stress block, neutral axis และ tension strain ของกรณี rectangular flexure ใช้ตรวจความสอดคล้องของขั้นตอนคำนวณ ไม่คัดลอกผลตัวอย่างหรือสรุปว่าแอปรองรับ girder ของเอกสารทั้งบท

[ACI Concrete Q&A — Effective Depth of Section with More Than One Layer of Reinforcement](https://www.concrete.org/publications/getarticle.aspx?m=icap&pubID=51740277)

ตารางที่อ้าง ACI 318-19(22) แสดงว่าการเป็น tension-controlled สำหรับเหล็ก nonprestressed ขึ้นกับ yield strain ด้วย จึงไม่ควรใช้ strength reduction factor คงที่กับเหล็กทุกปริมาณโดยไม่ตรวจ strain ก่อน กรณีอยู่นอกขอบเขตสมมติฐานของเครื่องมือให้รายงานว่าไม่ครอบคลุม แทนการให้สถานะผ่านจากสูตรที่ใช้ไม่ได้

การออกแบบโครงสร้างจริงยังต้องตรวจแรงเฉือน การโก่ง รอยร้าว ระยะเรียง/ระยะทาบและฝังเหล็ก รายละเอียดหน้าตัด load combinations และข้อกำหนดท้องถิ่นที่เกี่ยวข้อง แอปเวอร์ชันนี้เป็นเครื่องมือคำนวณที่เปิดเผยสมมติฐานสำหรับการทบทวนเบื้องต้น ไม่ใช่การรับรองแบบสำหรับก่อสร้าง

## สิ่งที่ยังไม่อยู่ในเวอร์ชันนี้

ความสามารถขั้นสูงที่เห็นในชื่อหรือคำอธิบายสาธารณะ เช่น 3D, FEA, AutoSolver, BBS, แบบฟอร์มราชการครบชุด, คู่มือ/แบบมาตรฐานฉบับเต็ม, current price feeds, คลังข้อสอบขนาดใหญ่ และการซิงก์ข้อมูลบนเซิร์ฟเวอร์ **ยังไม่ใช่ความสามารถของโครงการนี้** ไม่ได้ทดสอบระบบภายในต้นฉบับเพื่อยืนยันคำกล่าวอ้างเหล่านั้น

การพัฒนาต่อควรเริ่มจาก requirement และกรณีทดสอบของแต่ละเครื่องมือ แหล่งข้อมูลที่มีสิทธิ์ใช้ และมาตรฐาน/วิธีคำนวณฉบับที่ผู้ใช้เลือก ให้ตรวจสอบความถูกต้องได้เป็นรายการก่อนขยายขอบเขต
